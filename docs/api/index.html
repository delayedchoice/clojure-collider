clojure-collider.buffer

Server sample buffers. Mirrors buffer.lisp: alloc/read/write/cue/

helpers, list/array download, read-as-wavetable.

backspace escape -> "/b_gen").

clojure-collider.bus

Audio/control bus allocation. Mirrors bus.lisp.
Server is duck-typed (needs :lock, :audio-buses, :control-buses atoms)
so this ns never requires server.clj (no cycle). Unlike upstream, server
is always explicit (server.clj callers pass it).
floatfy stays numeric-only (synth.ugen); coerce buses via :busnum.

clojure-collider.core

Public re-export — mirrors the sc package export list.
Consumers can (:require [clojure-collider.core :as sc]).
Thread-local state has been eliminated: every server-taking fn receives
the server as its explicit first arg, so requiring this ns alone is
enough. Require the owning ns only for vars intentionally left there.
